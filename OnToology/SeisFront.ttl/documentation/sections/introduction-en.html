Introduction back to ToC

Seismic loss assessment with FEMA P-58 needs every building component assigned a fragility category, and this mapping has mostly been done manually. Earlier ontology-based work used SWRL rules for only two component types (RC beam-column joints and shear walls). SWRL rules are hard to write and maintain, and they do not exploit the hierarchy of the fragility database. SeisFront takes a different approach: it encodes the categories as a class hierarchy, so a reasoner can infer membership directly from component attributes.
