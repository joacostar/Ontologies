Light version of ifcOWL Ontology: Description back to ToC

Design: it imports ifcOWL for IFC4 and the Digital Construction Building Material Ontology. It keeps ifcOWL's classes, so the data still follows the IFC structure, and it defines new shortcut properties. Object properties link elements to related resources directly. Examples include ifcLit:hasProperty (element to property value), ifcLit:hasMaterial, ifcLit:hasMaterialReference and ifcLit:isInDistributionSystemPredefinedType. Datatype properties such as ifcLit:hasName and ifcLit:hasValue attach literals directly, so wrapper classes like ifc:IfcIdentifier and the numeric measure wrappers are no longer needed. Formal basis: each composite property can be written as an OWL property chain, e.g. ifcLit:hasProperty ≡ ifc:hasProperties ∘ ifc:relatingPropertyDefinition ∘ ifc:isDefinedBy.
